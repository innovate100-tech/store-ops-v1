# CAUSE OS · AI 도입 시 예상 효과 보고서

**관련 문서:** [음식점_배포_기획안_CAUSE_OS.md](./음식점_배포_기획안_CAUSE_OS.md)  
**문서 버전:** 1.0  
**작성 목적:** AI 기능 도입 시 예상되는 변화·가치·구현 방향 정리

---

## 1. 한 줄 요약

**현재 CAUSE OS는 “숫자와 QSC를 한곳에 모아 보여주는 도구”인데, AI가 붙으면 “숫자를 해석하고, 다음에 뭘 할지까지 말해 주는 경영 코치”로 바뀌며, 사장님이 직접 그래프·표를 해석하지 않아도 자연어로 질문·추천을 받을 수 있게 됩니다.**

---

## 2. 현재 상태 vs AI 도입 후 (전체 비교)

| 구분 | 현재 (AI 없음) | AI 도입 후 예상 |
|------|----------------|------------------|
| **역할** | 데이터 입력·시각화·계산 도구 | 데이터 기반 **대화형 경영 코치** |
| **사용 방식** | 메뉴·탭·차트를 직접 눌러서 확인 | “이번 주 뭐가 문제야?”처럼 **말로 질문** → AI가 분석 결과를 요약·추천 |
| **인사이트** | 사장님이 그래프·숫자를 보고 스스로 해석 | AI가 **원인·우선순위·다음 액션**을 문장으로 제안 |
| **입력 부담** | 매일 마감·정산 등 수동 입력 유지 | 입력 습관 유지 시 AI 추천 품질 상승 → **입력 동기 부여** |
| **전략 수립** | BEP·목표는 직접 계산·설정 | “목표 달성 가능해?” “이번 달 위험한 항목은?” 등 **질의·시뮬레이션** 지원 |

## 3. 기능별 AI 도입 예상 시나리오

### 3-1. 대시보드

| 현재 | AI 도입 시 예상 |
|------|------------------|
| 오늘 마감 여부, 최근 매출 추이, 입력 현황 카드 | **“오늘 한 줄 요약”**: “오늘 마감 전입니다. 지난 7일 평균 대비 매출 -12%라 주말 메뉴 프로모션을 검토해 보세요.” |
| 할 일 안내(마감 안 함, 목표 미설정 등) | **우선순위 제안**: “가장 먼저 오늘 마감을 입력하시면, 내일 아침 대시보드에서 주간 추이가 완성됩니다.” |
| 단순 숫자·차트 | **이상 징후 알림**: “이번 주 화요일 매출이 평소 대비 30% 낮습니다. 날씨/휴무/이벤트 중 원인을 메모해 두시면 다음 분석에 반영됩니다.” |

→ **바쁜 사장님이 “한 번에 핵심만”** 보도록, 대시보드 상단에 AI 요약/알림 블록을 둘 수 있음.

---

### 3-2. 입력 센터 (일일 마감·정산·목표·메뉴·발주)

| 현재 | AI 도입 시 예상 |
|------|------------------|
| 빈 칸 채우기, 탭별 입력 | **스마트 기본값**: 전날·지난주 같은 요일 매출을 참고해 “오늘 예상 매출” 제안 (사장님이 수정만 하면 됨) |
| “오늘 마감 안 함” 등 정적 안내 | **맥락별 안내**: “지난 3주 금요일은 평균 85만 원입니다. 오늘 입력값이 60만 원이면, 이유(재고/휴무 등)를 메모해 두시면 좋습니다.” |
| 메뉴·재료·레시피 수동 등록 | **자동 보완 제안**: “등록된 메뉴 12개 중 3개는 재료 연결이 없습니다. 이 메뉴들의 대표 재료를 제안할까요?” (선택적 적용) |
| 발주 참고만 제공 | **발주 추천**: “최근 7일 판매량 기준 A 재료는 2일 후 부족 예상. 발주 수량 제안: 00kg” (안전재고·리드타임 반영) |

→ **입력 시간 단축 + 입력 품질 향상**으로, 나중에 “분석·AI 코치”의 정확도도 함께 올라감.

---

### 3-3. 분석 센터 (매출·손익·목표·원가·메뉴·인력)

| 현재 | AI 도입 시 예상 |
|------|------------------|
| 탭별 차트·표, 기간 선택 후 직접 해석 | **자연어 질의**: “지난달 매출 왜 떨어졌어?” → “목표 대비 -8%, 주로 2주차 주중 매출 감소. 그 주 날씨/이벤트를 확인해 보세요.” |
| 메뉴 구조 분석에서 비중만 확인 | **메뉴 인사이트**: “메뉴 A는 매출 비중 25%인데 이익 기여는 8%입니다. 가격·원가 재검토를 추천합니다.” |
| 인력 분석에서 인건비·매출만 표시 | **인력 추천**: “피크타임 대비 평일 낮 인건비 비율이 높습니다. 요일별 스케줄 조정을 제안합니다.” |
| 원가 분석 표·비율만 제공 | **원가 알림**: “이번 달 재료비 비율이 전월 대비 +3%p입니다. 상위 3개 재료(OO, OO, OO) 가격 변동을 확인해 보세요.” |

→ **“그래프는 보이는데 결론을 못 내리겠다”**는 상황을, **문장 형태의 결론·추천**으로 보완.

---

### 3-4. 데이터 전략 센터 (BEP·목표·비용 구조)

| 현재 | AI 도입 시 예상 |
|------|------------------|
| BEP·목표 수치 직접 입력·계산 | **AI 전략 코치(대화)**: “이번 달 목표 달성 가능해?” → “현재 페이스로는 92% 예상. 남은 10일 일평균 00만 원 추가 필요.” |
| 비용 항목별 입력 후 구조만 표시 | **시뮬레이션**: “인건비 10% 줄이면 BEP가 얼마나 내려와?” → “약 00만 원 하락. 단, 서비스(QSC) 점수 하락 리스크 있음.” |
| 정적 배너 + AiChatMock(준비중) | **실제 채팅**: “이번 주 제일 먼저 고칠 건 뭐야?” → “인건비 과다. 스케줄/피크타임 배치 점검 추천.” (현재 목업 문구를 실제 데이터 기반 답변으로 대체) |

→ **전략 센터가 “계산기”에서 “질문하면 답해 주는 코치”**로 진화.

---

### 3-5. QSC (품질·서비스·청결)

| 현재 | AI 도입 시 예상 |
|------|------------------|
| 점검 항목 체크·실패/개선 기록 | **실패 패턴 요약**: “최근 2주 ‘청결(C)’ 항목 실패가 5회로 가장 많습니다. 화장실/바닥 점검 주기를 줄이면 좋겠습니다.” |
| 레이더 차트로 9요소 강·약점 시각화 | **우선순위 제안**: “지금은 S(서비스)와 C(청결)를 먼저 올리는 게 매출 대비 효과가 큽니다. 이번 주 QSC 전략센터 액션 2개만 골라 실행해 보세요.” |
| 집중 개선 항목을 수동 선택 후 전략센터로 전송 | **자동 추천 액션**: “실패 빈도 + 최근 트렌드를 반영해 이번 주 추천 액션 3개를 만들어 뒀어요. 전략 센터에서 확인하세요.” |

→ **QSC가 “기록”에서 “어디를 고칠지까지 제안”**하는 단계로 올라감.

---

### 3-6. 메뉴·재료·발주 (입력 + 분석 연계)

| 현재 | AI 도입 시 예상 |
|------|------------------|
| 메뉴·재료·레시피 수동 등록 | **이름/단위 정리 제안**: “비슷한 재료명이 3건 있습니다. 통합할까요?” (중복·오타 정리) |
| 발주는 참고 탭 위주 | **발주 추천** (위 3-2 참고): 판매 이력·안전재고 기반 수량·시점 제안 |
| 원가 분석과 메뉴 분석 분리 | **통합 인사이트**: “메뉴 B 원가율이 올라갔어요. 연결된 재료 OO 가격이 전월 대비 +15%입니다.” |

→ **메뉴·재료·발주 데이터가 “AI가 해석 가능한 자산”**이 되면, 분석·전략 품질이 동시에 좋아짐.

## 4. 사장님 관점에서의 기대 효과 (정리)

| 기대 효과 | 설명 |
|-----------|------|
| **해석 부담 감소** | 숫자·차트를 직접 해석하지 않아도, “무슨 일이 있었는지·뭘 먼저 할지”를 문장으로 받을 수 있음 |
| **다음 액션 명확화** | “이번 주 제일 먼저 고칠 건 뭐야?”처럼 질문하면, 데이터 기반으로 1~3개 액션을 우선순위와 함께 제안 |
| **입력 동기 강화** | “입력하면 AI가 더 정확한 조언을 준다”는 명확한 보상이 있어, 마감·정산·QSC 입력 습관 유지에 도움 |
| **시간 절약** | 여러 탭·기간을 넘나들지 않고, 대시보드·채팅 한 곳에서 요약·추천을 받아 결정 속도 향상 |
| **전략 시뮬레이션** | “목표 달성 가능해?”, “인건비 줄이면?” 같은 가정 질의에 대해 수치·리스크까지 짧게 답변 |

## 5. 구현 시 고려할 점 (예상)

| 구분 | 내용 |
|------|------|
| **데이터 기반 답변** | AI는 반드시 **실제 저장된 데이터**(daily_close, targets, QSC, 메뉴·재료 등)만 참조해 답변하도록 설계. 없는 데이터는 “데이터가 없어서 답할 수 없음”으로 명시 |
| **역할·권한** | 매장별·역할별로 접근 가능 데이터가 다르다면, AI 답변 범위도 동일하게 제한 (예: 점장은 해당 매장만) |
| **비용·한도** | LLM API 호출 비용·일일 질문 횟수 한도 등을 초기부터 정책으로 두고, 무제한 사용 시 부담이 가지 않도록 설계 |
| **환각 방지** | “수치·날짜·금액”은 가능한 한 **앱이 계산한 값**을 AI에게 컨텍스트로 넘기고, AI는 해석·문장화만 담당하도록 하면 오답·환각 감소 |
| **점진적 도입** | 현재 **전략 센터의 AI 전략 코치(목업)** 를 먼저 실제 채팅으로 전환한 뒤, 대시보드 요약 → 분석 질의 → 입력 추천 순으로 확장하는 단계적 로드맵 권장 |

---

## 6. 리스크와 완화 방안 (요약)

| 리스크 | 완화 방안 |
|--------|-----------|
| AI가 잘못된 숫자·원인을 말함 | 수치는 앱이 계산한 값만 전달하고, AI는 “해석·추천 문장”만 생성. 필요 시 “근거: OO 탭 OO 기간” 링크 표시 |
| “AI만 믿고 판단”으로 잘못된 결정 | 모든 AI 답변에 “참고용이며, 최종 판단은 사장님 판단입니다” 등 디스클로저 표기 |
| 입력이 부족한 매장에서 AI 품질 저하 | “데이터가 부족해 정확한 추천이 어렵습니다. 일일 마감·목표를 쌓아 주세요.” 안내 + 입력 센터 연동 유도 |
| API 장애·지연 시 사용자 불만 | “AI 답변이 지연되고 있습니다” 등 상태 표시, 필요 시 폴백으로 기존 차트·표만 보여 주기 |

---

## 7. 정리

- **AI가 붙으면** CAUSE OS는 **“데이터를 보여 주는 도구”에서 “데이터를 해석하고 다음 행동을 제안하는 경영 코치”**에 가까워집니다.
- **대시보드·입력·분석·전략·QSC·메뉴·발주** 각 영역에서 **자연어 질의, 요약, 우선순위 제안, 스마트 기본값·발주 추천** 등이 단계적으로 추가될 수 있습니다.
- **사장님 관점**에서는 해석 부담 감소, 다음 액션 명확화, 입력 동기 강화, 시간 절약, 전략 시뮬레이션이 기대됩니다.
- **구현 시**에는 데이터 기반 답변, 권한·비용·한도, 환각 방지, 점진적 도입(전략 센터 AI 코치 → 대시보드 → 분석·입력)을 우선 고려하는 것이 좋습니다.

이 보고서는 **AI 도입 시 “무엇이 어떻게 달라질지”**를 기획·영업·개발에서 공유하기 위한 예상 정리 문서입니다. 실제 기능 범위와 우선순위는 제품 로드맵에 따라 조정하면 됩니다.
